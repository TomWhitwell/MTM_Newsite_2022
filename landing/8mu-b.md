      <h2>Use USB-C or 3.5mm MIDI.</h2>
    </div>
    <div>
      <p>USB-C is simplest with a computer. The hardware MIDI output can be set to Type A or Type B in the editor, so it can work with different hardware standards.</p>
      <p>MIDI Learn modes help when mapping controls, especially if the accelerometer channels are sending extra movement data.</p>
