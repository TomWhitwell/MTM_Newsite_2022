      <h2>Radio Music</h2>
      <p>Best if you want the classic 4HP idea: tune files, set start, reset, pitch, CV. Small, direct, and enough for a lot of patches.</p>
      <ul>
        <li>4HP</li>
        <li>MicroSD sample playback</li>
        <li>Station and reset behaviour</li>
        <li>Lowest cost and smallest rack space</li>

      <span>Option 2</span>
      <h2>Radio Music + Remote</h2>
      <p>Best if you want to perform speed, loop points and modes. More space outside the rack, much less fiddling with hidden settings.</p>
      <ul>
        <li>Hands-on speed and loop window</li>
        <li>Mode changes while playing</li>
        <li>Motion button for the possibly unwise ideas</li>
        <li>Feels more like an instrument pair</li>

      <h2>Something else</h2>

      <ul>
        <li>No screen</li>
        <li>No waveform editor</li>
        <li>No project system</li>
        <li>Very much a modular instrument</li>

  <section class="lp-section">
    <p class="lp-kicker">Buying quiz</p>
    <h2>A slightly bossy decision tree, because this format is allowed to be useful.</h2>
    <div class="lp-comparison lp-comparison--four">
      <div><strong>Do you mostly want long recordings?</strong><span>Start with Radio Music. Spend the extra money on a good SD card and time making banks.</span></div>
      <div><strong>Do you want to grab loop points live?</strong><span>Get the Remote. That is exactly what the extra faders are for.</span></div>
      <div><strong>Do you hate settings files?</strong><span>Remote again. It makes the most common settings visible, which is sometimes worth more than another module.</span></div>
      <div><strong>Do you need slicing?</strong><span>Buy a different sampler. This page should be confident enough to say that.</span></div>
    </div>
  </section>

  <section class="lp-config__objections" id="questions">
    <div><strong>"I hate SD card admin."</strong><p>Fair. Start with one folder and ten files. The page should show that the simple version works before explaining every clever folder rule.</p></div>
    <div><strong>"I already have a sampler."</strong><p>Good. This is not a replacement for a serious sampler. It is a different way of letting recordings live inside a patch.</p></div>
    <div><strong>"Do I need the Remote now?"</strong><p>No. But if the demo that made you want it involved sliding loop points and changing speed with both hands, yes, probably.</p></div>
  </section>
