    <div class="lp-section-copy">
      <p class="lp-kicker">The thing to understand first</p>
      <h2>The selected sample changes, but the unselected samples do not go to sleep.</h2>
      <p>This was the original Radio Music trick, and it is still the reason the module is interesting. If you have ten long recordings on the card, all ten can feel as if they are quietly running. Turn Station and you drop into a different one, already in progress. It is a very small idea, but it changes the whole feeling of using samples in a modular.</p>
    </div>
  </section>

  <section class="lp-section lp-section--story">
    <p class="lp-kicker">Why this is useful</p>
    <h2>It gets recorded sound out of the computer and into the habit of patching.</h2>
    <div class="lp-story-grid">
      <div>
        <h3>Make banks like places</h3>
        <p>One bank can be shortwave. One can be family voices. One can be bits of a record you made ten years ago. The point is not to organise a library perfectly. The point is to make a small world you can tune around.</p>
      </div>
      <div>
        <h3>Let the patch choose</h3>
        <p>CV can move through Stations. Reset can trigger a file. Random folders can answer a pulse differently each time. This is where a sample player starts to feel like a member of the patch rather than a backing track.</p>
      </div>
      <div>
        <h3>Learn by hearing it happen</h3>
        <p>Start point, pitch, direction, looping, reset timing: these can sound like a manual until you patch them. Then they become extremely obvious, in the nice physical way modular can make things obvious.</p>
      </div>
    </div>
  </section>

        <span>01</span>
        <h3>Station is the main event</h3>
        <p>Turn it by hand or use CV. In the clean mode it selects one sound. In soft mode it blends between neighbours. In radio mode it behaves more badly, in a good way, with noise and tuning gaps.</p>
      </div>
      <div>
        <span>02</span>
        <h3>Reset makes recorded sound rhythmic</h3>
        <p>Press the button or send a pulse. Restart a loop, stutter a word, fire a drum hit, or make a long recording lock to a patch just enough to be useful and not so much that it becomes tidy.</p>
      </div>
      <div>
        <span>03</span>
        <h3>Pitch mode is where it becomes properly odd</h3>
        <p>Tap the Start knob and it stops choosing a start point and starts changing speed. Forward, backward, tape-ish, calibrated 1V/oct if you want to do the sensible melodic thing.</p>
      </div>
      <div>
        <span>04</span>
        <h3>The new version removes old annoyances</h3>
        <p>Better audio, lower latency, WAV and AIFF up to 24-bit / 96kHz, big modern microSD cards, a built-in card reader mode, and no hunt for increasingly mythical Teensy 3.2 boards.</p>
      </div>

  <section id="remote-details" class="lp-section">
    <p class="lp-kicker">Four useful kinds of wrongness</p>
    <h2>The Remote makes Radio Music less polite.</h2>
    <div class="lp-card-grid lp-card-grid--four">
      <div class="lp-card"><h3>Tape</h3><p>Linear speed control. Stop it, reverse it, push it too far, bring it back. The old reliable trick because it still works.</p></div>
      <div class="lp-card"><h3>Notes</h3><p>Exponential pitch, quantised if you want it, so a recording can become an oscillator-ish voice without pretending to be a proper oscillator.</p></div>
      <div class="lp-card"><h3>90s</h3><p>The sound of bad time-stretching becoming good again because enough time has passed.</p></div>
      <div class="lp-card"><h3>Radio</h3><p>Tuning gaps, noise, distortion. Not accurate radio modelling, thank goodness. A musical version of the idea.</p></div>
    </div>
  </section>

  <section class="lp-section lp-section--faq">
    <p class="lp-kicker">Things people ask</p>
    <h2>Good questions, because this is a slightly odd module.</h2>
    <details open><summary>Is it actually a radio?</summary><p>No. There is no antenna. It plays your files. But it can behave enough like a radio to make your files feel less like a list and more like a place.</p></details>
    <details><summary>Do I need Radio Remote?</summary><p>No. Start with Radio Music if you want the small, classic thing. Add Remote if you want to perform speed, loop points and modes without thinking about settings files.</p></details>
    <details><summary>Is it only for field recordings?</summary><p>No. That is the romantic use, and I like it, but it can be a drum source, a one-shot player, a phrase machine, a tape loop, or a peculiar clocked sound source.</p></details>
