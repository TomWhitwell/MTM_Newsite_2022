  <section id="overview" class="sale-section sale-section--split">
    <div>
      <p class="sale-kicker">The main behaviour</p>
      <h2>Files keep playing in the background.</h2>
    </div>
    <div>
      <p>Radio Music is more interesting than a file selector. If a bank contains long recordings, changing Station can drop into another recording already in progress. That is the radio-like part: the module feels less like browsing a menu and more like moving across a band of sound.</p>
      <p>It also works with short files. Reset can retrigger loops, one-shots and drum hits. Station CV can move through a bank. Start/Pitch CV can set a start point or control pitch, depending on mode.</p>
    </div>
  </section>

  <section class="sale-faq">
    <h2>Questions</h2>
    <details open><summary>Is it a radio?</summary><p>No. It plays your files from microSD. The radio part is the way Station moves through files.</p></details>
    <details><summary>Do I need Radio Remote?</summary><p>No. Buy Radio Music first if you want the smallest system. Add Remote if you want live control of speed, loop points and modes.</p></details>
    <details><summary>Can it replace a screen sampler?</summary><p>No. It is for fast patching and performance, not waveform editing or project management.</p></details>
