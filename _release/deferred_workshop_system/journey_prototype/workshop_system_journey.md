    <h1>Music Thing Modular Workshop System</h1>
    <p>Workshop System is a complete modular synth, slightly smaller than a hardback book, in a foam-lined hard case.</p>
    <p>At present, it is available as an <a href="https://www.thonk.co.uk/shop/mtm-workshop-assembled/">assembled unit</a> or <a href="https://www.thonk.co.uk/shop/workshop-system/">DIY kit</a> from Thonk in Brighton, and from <a href="/buy/">retailers around the world</a>.</p>

  <section class="workshop-journey__notes" aria-label="Workshop System notes">
    <h2>What is inside?</h2>
    <p>Two oscillators, two filters, two Slopes, Computer, Stereo In, Ring Mod, Stompbox, Amplifier, 4 Voltages, Mix and a power supply behind the panel.</p>
    <p>It is a synth, but also a small workshop: patchable, hackable, codeable and very easy to use in the wrong way.</p>
